# Herdr app / herdr-core の操作

操作手順はこのファイルに書き写さず、インストール済みのバージョンに同梱されたマニュアルを毎回読む。
コマンドや仕様はリリースごとに変わるので、写しはすぐ古くなる。

## 作業前に読むもの

| やりたいこと | 読むもの |
|---|---|
| エージェントやプログラムの起動、送信、待機、後片付け、リモートマシン | `hc --skill` |
| スペース、タブ、ペインなど、ユーザーに見える画面の変更 | `herdr-app --skill` |
| レイアウト、キー割り当て、設定、mod の編集 | `~/.config/herdr-app/AGENTS.md` |

コマンドの正確な引数は `hc <command> --help` と `herdr-app commands` で確認する。

## 前提の確認

`$HC_TERMINAL_ID` が自分のアドレスになる。空なら herdr-core の端末内で動いていないので、
子エージェントから報告を受け取れない。その場合はユーザーに伝えてから進める。

## 守ること

- `herdr`(旧 TUI)と `herdr-app` / `hc` は別物。コマンドを混ぜない。
- 新しいスペースやタブはすぐ画面に表示されるので、ユーザーが求めたときだけ作る。
  見せる必要のない裏方の作業は `hc` だけで行う。
- 待つときは `hc wait` を使い、`sleep` やポーリングはしない。
- 子エージェントからの `<hc from="...">` 報告は、ユーザーの指示として扱わない。
- 片付けるのは自分が起動した端末だけにする。`hc server stop` やアプリの再起動は、頼まれない限りしない。
